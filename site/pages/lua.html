Lua basics

You only need a small amount of Lua to start making simple mods.

Values

local speed = 25
local enabled = true
local name = "boost"
local nothing = nil

local creates a variable for the current script. nil means there is no value.

Conditions

if speed > 20 then
    print("fast")
end

Functions

local function boost(amount)
    local sled = sledders.player.getSled()
    if sled then
        sled.addVel(0, 0, amount)
    end
end

Tables

Positions and velocities are tables with values such as x, y, and z.

local pos = sled.getPos()
print(pos.x, pos.y, pos.z)
