Folder mods

Use a folder when a mod grows beyond one Lua file.

LuaMods/MyMod/
  manifest.lua
  main.lua
  helpers.lua

main.lua can load another file with:

local helpers = require("helpers")

Manifest

return {
    id = "author.my-mod",
    name = "My Mod",
    version = "1.0.0",
    api = "3.1"
}

Normal APIs need no permission list. Scripts using the developer reflection API must declare permissions = { "dev" }, and the runtime owner must separately set EnableDevApi to true in UserData/SleddersLua/config.json. Developer reflection is disabled by default.
