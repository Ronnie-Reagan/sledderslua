Folder mods

Use a folder when a mod grows beyond one Lua file.

LuaMods/MyMod/
  manifest.lua
  main.lua
  helpers.lua

main.lua can load another file with:

local helpers = require("helpers")

Manifest

return {
    id = "author.my-mod",
    name = "My Mod",
    version = "1.0.0",
    api = "3.2"
}

Normal APIs need no permission list. Developer reflection requires both permissions = { "dev" } and owner-side EnableDevApi=true; normal framework APIs require neither.
