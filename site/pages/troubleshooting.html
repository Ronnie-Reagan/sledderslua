Troubleshooting

The runtime does not appear in MelonLoader

Check that Mods/SleddersLuaRuntime.dll exists and that MelonLoader itself is working.

MoonSharp is missing

Check UserLibs/MoonSharp.Interpreter.dll. Re-extract the runtime release if it is missing.

My script does not load

A single-file mod must end in .lua and sit directly in LuaMods. A folder mod must contain main.lua.

I saved broken Lua

A syntax error or top-level runtime error during hot reload leaves the last working copy running. Fix the file and save it again.

sledders.dev says it is disabled

Developer reflection is disabled by default. The mod must declare permissions = { "dev" } and the runtime owner must set EnableDevApi to true in UserData/SleddersLua/config.json, then restart Sledders.

A callback stopped running

Check the MelonLoader console. A callback that throws an error is suspended until the script reloads.

A binding broke after a Sledders update

Include the Sledders version and MelonLoader log in the bug report.
