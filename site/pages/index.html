Sledders Lua

Write Sledders mods as Lua scripts. A useful mod can be one text file, while the stable framework also covers tuning, physics, native HUD, camera/photo mode, audio, materials, world state, scene objects and assets.

New to coding?Make your first mod.
Installing?Install the runtime, then install Lua mods.
Building serious mods?Use the API reference and framework examples.

Low barrier

local sled = sledders.player.getSled()
if sled then
    sled.addVel(0, 0, 10)
end

High ceiling

local sled = sledders.player.getSled()
local vehicle = sled and sled.getVehicle()
if vehicle then
    vehicle.setHorsepower(200)
end

Ordinary mods should not need raw reflection. Stable subsystem wrappers expose Sledders/game concepts and safe Unity-backed objects directly.
