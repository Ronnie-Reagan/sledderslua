Sledders Lua

Write Sledders mods as Lua scripts. A mod can be one text file, and changed scripts reload while the game is running.

New to coding?Make your first mod.
Installing?Install the runtime, then install Lua mods.
Already know Lua?Use the API reference and examples.

Basic idea

local sled = sledders.player.getSled()
if sled then
    sled.addVel(0, 0, 25)
end

The runtime handles the Sledders and Unity details behind that API. Lua mods do not need their own C# project or DLL.
