Sled

Get the local player's sled from sledders.player.

local sled = sledders.player.getSled()
if not sled then return end

Movement

getVel, setVel, addVel, and addForce use sled-local axes:

X = right
Y = up
Z = forward

Methods containing WorldVel or WorldForce use fixed world axes.

Position

setPos and teleport move the live sled through the game's movement/respawn path when that binding is available.

Headlights

setHeadlights and toggleHeadlights change the normal game state once. forceHeadlights keeps an override active until releaseHeadlights.

See the API reference for the full function list.
