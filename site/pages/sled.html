Sled

Get the local player's sled from sledders.player.

local sled = sledders.player.getSled()
if not sled then return end

Common state

The convenience sled wrapper covers position/rotation, local and world velocity, angular velocity, forces/torques, engine, fuel, headlights and common state.

getVel/setVel and addForce use sled-local axes:

X = right
Y = up
Z = forward

Methods containing World use fixed world axes.

Separate subsystem objects

local vehicle = sled.getVehicle()  -- definition/spec values
local body = sled.getBody()        -- live Rigidbody physics
local tuning = sled.getTuning()    -- controller/suspension/shocks
local structure = sled.getStructure()

vehicle.getWeight() and body.getMass() are intentionally separate concepts.

Visual parts

local hood = sled.getRenderers("hood")
local material = hood[1] and hood[1].getMaterial()
