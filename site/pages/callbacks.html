Callbacks

Callbacks are functions the runtime calls for you. Define only the ones your mod needs.

function onLoad()
end

function onTick(dt)
end

function onDraw()
end

function onKey(key)
end

dt is elapsed time in seconds. Use onTick for normal repeated logic and onDraw for screen drawing.

If a repeating callback throws an error, that callback is suspended until the mod reloads instead of filling the console every frame.
