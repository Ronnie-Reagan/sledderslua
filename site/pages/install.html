Install the runtime

Sledders and MelonLoader 0.7.1 must already be installed.

Download the latest release Browse nightly builds

  1. Close Sledders.
  2. Extract the Sledders Lua release ZIP into the Sledders game folder.
  3. Start Sledders.
Sledders/
  Mods/SleddersLuaRuntime.dll
  UserLibs/MoonSharp.Interpreter.dll
  LuaMods/
  SleddersLua/

The MelonLoader console should list Sledders Lua Runtime during startup.

MelonLoader is not included in the release ZIP.
