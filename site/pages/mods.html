Install Lua mods

Put downloaded Lua mods in Sledders/LuaMods.

Single file

LuaMods/MyMod.lua

Folder mod

LuaMods/MyMod/
  main.lua
  manifest.lua

Most scripts can be added or changed while Sledders is running. Saving a changed Lua file reloads that mod.

Top-level files and mod folders beginning with _ are ignored by the loader.
