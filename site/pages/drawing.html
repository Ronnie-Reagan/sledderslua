Drawing

Use sledders.screen from onDraw() for simple HUDs and overlays.

function onDraw()
    sledders.screen.setColor(255, 255, 255)
    sledders.screen.print("hello", 20, 20)
end

The screen API also has rectangles, boxes, lines, circles, triangles, and polygons. See SimpleHUD.lua for a small working HUD.
