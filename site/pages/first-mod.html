Make your first mod

Start with a working example and change one thing.

  1. Open SleddersLua/Examples.
  2. Copy ForwardBoost.lua into LuaMods.
  3. Rename it to MyBoost.lua.
  4. Open it in a text editor.
  5. Change the boost number and save.
sledders.input.onPressed("space", function()
    local sled = sledders.player.getSled()
    if not sled then return end
    sled.addVel(0, 0, 25)
end)

Change 25, save the file, and test again. If the script has an error, the MelonLoader console normally shows the file and line.
